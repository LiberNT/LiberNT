GNOME Project (http://www.gnome.org), taken from
https://gitlab.gnome.org/GNOME/adwaita-icon-theme and, where the name is
prefixed with AdwaitaLegacy, from
https://gitlab.gnome.org/GNOME/adwaita-icon-theme-legacy. Both themes state:

  When attributing the artwork, using "GNOME Project" is enough.
  Please link to http://www.gnome.org where available.
